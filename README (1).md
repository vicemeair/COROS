# COROS UNLOCKED — V0.1

Projet indépendant destiné à explorer les possibilités de personnalisation de la COROS PACE 4.

## Fichiers
- `index.html` : structure du site et sections App Store / Watch Creator / Watch Lab.
- `style.css` : design responsive.
- `app.js` : mini-apps interactives et aperçu de cadran.

## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub nommé `coros-unlocked`.
2. Ajoute ces trois fichiers à la racine du dépôt.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
4. Enregistre puis attends la publication.

## Limite technique importante
Cette version ne permet PAS d'installer des applications sur une COROS PACE 4. Les mini-apps tournent dans le navigateur et le Watch Creator exporte une image PNG de démonstration, pas un cadran installable. Le Watch Lab sert à documenter les recherches avant tout test sur la montre.
